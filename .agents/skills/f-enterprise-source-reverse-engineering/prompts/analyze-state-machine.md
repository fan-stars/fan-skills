# 分析状态机

分析 Project `${project}` 的 `${module}` 中实体 `${entity_or_all}` 的状态机。

读取状态常量/枚举、数据库字段、条件判断、更新语句、接口、Job、事件和错误处理。对每条迁移记录原状态、目标状态、触发方式、前置条件、操作者、数据库更新、副作用、失败处理、并发风险、project、哈希、符号和行范围。识别非法迁移、孤立状态、终态和补偿路径。

输出 state-machine 文档和 business index 状态/迁移条目。仅名称或字段值推测的状态标 `UNRESOLVED`；多处实现冲突标 `CONFLICT`。没有实际更新证据的迁移不得标 FACT，也不得修改源码。
