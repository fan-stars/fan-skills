# 比较 A/B 同类模块

比较 Project A 与 Project B 的 `${module}` 模块，新增需求为 `${requirements}`。

先验证双方模块至少 PARTIAL、文档存在、证据未过期、边界可对齐；任一条件失败只输出阻塞清单。满足后按职责、能力、数据模型、API、业务规则、状态机、金额、库存、事务、并发、幂等、缓存、消息、外部服务、权限、正确性、维护性、扩展性、缺陷和迁移难度逐项比较。

每项结论引用 A-*、B-* 和相关 REQ-*，分别保留双方事实，不把一方实现写成另一方事实。输出 10 类 comparison 文档、优势/弱点、冲突、候选决策和 open questions。不得直接生成 Java 代码或在证据不足时选择“最佳方案”。
