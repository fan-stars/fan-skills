# 模块匹配评分标准（默认阈值 0.95）

每完成一个模块切片后，用 Playwright 对比 **legacy（要重构站）**、**reference（参考站，如有）**、**rewrite（本站）**。

## 原则

- 默认 `matchScope: information-architecture`：IA / 流程 / 关键文案 / 区块顺序 / 交互，**以及**下列视觉与交互 chrome 细则。
- **不是**整包拷贝旧站 CSS；下列分项须达到量级一致。若用户/配置改为 `pixel`，则按像素级更严执行。
- 参考站与 legacy 冲突时，以 **legacy + grill 结论** 为准。
- 旧站**无**某能力 → 该项记 **N/A**，不计入平均分母。
- 字距/段距并入「字体」抽样；cursor 并入 hover / 可点控件；不单列吵项。

## 评分表（等权，每项 0～1；N/A 排除）

### A. 结构与行为

| # | 维度 | 1.0 标准 |
| --- | --- | --- |
| 1 | 区块存在与顺序 | 应出现的子区齐全、顺序一致（含显隐） |
| 2 | 关键文案 | 标题、主按钮、空态等与 legacy（或配置源）一致或可追溯 |
| 3 | 交互行为 | Tab / 展开 / 轮播 / 链接目标等行为一致 |
| 4 | 显隐语义 | hidden/visible 与源码 + 线上一致 |
| 5 | 布局骨架 | 栏数、主从关系、对齐方式一致 |
| 6 | 对齐与间距节奏 | 左缘/基线对齐；栏间距、卡片 gap 均匀，不「歪一截」 |

### B. 视觉与 chrome（必评；有则评、无则 N/A）

| # | 维度 | 1.0 标准 | 取证建议 |
| --- | --- | --- | --- |
| 7 | **字体** | 字族风格接近；字号 / 字重 / 行高 / 字色（及字距若显著）量级一致；标题、正文、辅助文分别抽样 | font-* / color / letter-spacing |
| 8 | **背景** | 区块/卡片/条带背景色或渐变/图量级一致（含透明顶栏等） | background-color / image |
| 9 | **边距** | margin / padding / gap 与抽样量级一致 | margin / padding / gap |
| 10 | **大小** | 关键盒宽高、图标/图片显示尺寸量级一致 | width / height |
| 11 | **边框 / 分割线** | 颜色、粗细、虚实（卡片描边、区块顶底边）一致 | border / border-color |
| 12 | **圆角** | 卡片/按钮/输入框/图片 border-radius 量级一致 | border-radius |
| 13 | **阴影 / 层级** | box-shadow、遮罩、浮层是否盖住正确内容 | box-shadow / z-index / 截图 |
| 14 | **主色 / 状态色** | 链接色、激活色、成功/危险等与旧站或站务主色一致 | color / 主题变量 |
| 15 | **图标 / 图片** | 有无、尺寸、裁切/object-fit；缺图时不乱插无关 Icon | 节点 + object-fit |
| 16 | **Hover（如有）** | 悬停后颜色、下划线、位移、阴影、背景变化一致 | hover 前后 computed + 截图 |
| 17 | **激活 / 选中态（如有）** | Tab/侧栏/分页等激活态（下划线、字色等），与 hover 区分 | 激活项样式 |
| 18 | **角标（如有）** | HOT/推荐/丝带等位置、形状、色、字号一致 | 角标几何与样式 |
| 19 | **动效（如有）** | 过渡时长/缓动接近；无多余动画；旧站有短过渡时本站勿「瞬切」违和 | transition / animation |
| 20 | **透明度 / 叠层（如有）** | 透顶栏、叠字、半透明条 opacity/叠放顺序一致 | opacity / 层叠截图 |
| 21 | **滚动与溢出（如有）** | 横向滚动、line-clamp、marquee 行为与样式一致 | overflow / clamp |
| 22 | **焦点 / 禁用 / 加载（如有）** | focus 可见、disabled、骨架/加载态与旧站量级一致 | :focus / disabled / 空态 |

### C. 工程约束

| # | 维度 | 1.0 标准 |
| --- | --- | --- |
| 23 | 无回归 | 已达标模块未破坏；无致命控制台错误 |
| 24 | UI 库约束 | 无未批准自定义组件 |
| 25 | 响应断点（若本轮承诺） | 仅当模块明确要求桌面+移动均达标时评分；否则 N/A |

**得分** = 所有非 N/A 项的算术平均。`score >= matchThreshold`（默认 **0.95**）→ 通过。

任一项**关键缺失**（整块不存在、错误数据源、未批准自定义、字体/边距/主色等与抽样严重偏离）→ 该项记 **0**，通常直接不及格。

## 抽样要求（B 组）

每个模块至少：

1. 模块标题 + 一段正文（字体、主色）  
2. 模块根容器或主卡片（背景、边距、大小、边框、圆角、阴影）  
3. 一个可点击主控件（hover；若有激活态另采一处）  
4. 一处图标或图片（若有）  
5. 一处角标（若观测/源码表明存在）  
6. 动效 / 透叠 / 溢出 / 焦点禁用加载：仅当旧站存在时抽样  

将数值写入 `matches/` 记录的「抽样」表，便于复评。

## 未通过时

1. 列出 Gaps（优先视觉 B 组）→ 只改本模块。  
2. 再跑 Playwright 对比。  
3. 仍 < 阈值 → 继续调整；**不得**开始下一模块。
