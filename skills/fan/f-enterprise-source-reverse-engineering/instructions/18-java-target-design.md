# Java 目标设计

## 目标
根据已批准证据和需求设计 Java 模块，而非复制 PHP 目录。

## 输入
A/B 模块文档、比较报告、决策登记、新需求、相关模块摘要和全局 Java 约束。

## 执行步骤
按领域边界设计目标、模型、用例、规则、状态、API、数据库、事务、并发、事件、缓存、安全、错误码、包结构、测试和迁移；标记来源类型。

## 输出
java-target 模块文档、需求追踪、决策记录和实现前风险清单。

## 质量检查
每项可追溯到 A/B/REQ；区分 ADOPT_A、ADOPT_B、MERGE、REDESIGN、NEW_REQUIREMENT；不生成逐行 Java 代码。

## 失败处理
来源缺失或冲突未决时暂停该设计项，标 REVIEW_REQUIRED 并返回比较阶段。
