# PC spacing baseline

Use only as a starting hypothesis and verify the current design, density, and installed token values.

| Relationship | Preferred token | Typical default |
| --- | --- | ---: |
| Page horizontal padding | `paddingXL` | 32px |
| Page top padding | `paddingLG` | 24px |
| Page bottom padding | `paddingXL` | 32px |
| Section gap | `marginXL` | 32px |
| Module gap | `marginLG` | 24px |
| Module content gap | `margin` | 16px |
| Component internal gap | `marginSM` | 12px |
| Element gap | `marginXS` | 8px |
| Micro gap | `marginXXS` | 4px |

Choose constrained max-width for marketing, reading, detail, and user-center content when appropriate. Prefer full width for dashboards, tables, and workbenches. Centralize content widths at the layout layer; dimensions such as 1200/1280/1440px are constraints, not spacing tokens.
