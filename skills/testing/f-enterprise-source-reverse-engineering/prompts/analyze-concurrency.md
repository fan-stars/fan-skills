# 分析并发与幂等

分析 Project `${project}` 的 `${module}`，重点场景 `${scenarios}`。

检查事务、行锁、FOR UPDATE、乐观锁、Redis 锁、唯一约束、业务单号、幂等键、重复回调、重复消息和重试。构造取消/支付、支付/退款、库存扣减/释放等并发时序，逐个映射读取、条件判断、写入、副作用、失败补偿和最终状态。

输出场景矩阵、已有保护、竞态窗口、幂等规则、风险等级和源码证据。区分 FACT、INFERENCE 与 RISK；没有锁、唯一键或状态条件证据时不能声称安全。不要运行会写真实业务数据的并发试验，也不得修改源码。分析失败时保留已验证场景，标记其余场景 `UNRESOLVED` 并记录缺失输入。
