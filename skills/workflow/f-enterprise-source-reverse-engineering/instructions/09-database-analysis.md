# 数据库分析

## 目标
还原模块表结构、字段语义和代码读写关系。

## 输入
DDL、migration、Model、Repository、query builder、raw SQL、事务和锁证据。

## 执行步骤
记录字段、键、索引、外键、状态、枚举、金额/时间单位、JSON、软删除、审计、租户、分片和快照，反向列出读写方法。

## 输出
表清单、字段字典、读写矩阵和关联分类。

## 质量检查
区分数据库外键、代码关联、命名相似和未知；关键字段都有 DDL 或使用证据。

## 失败处理
DDL 缺失时使用代码查询作为 `INFERENCE`；冲突字段登记 CONFLICT，不自行合并。
