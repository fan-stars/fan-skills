# 项目比较

## 目标
只在证据就绪后比较 A/B 同类模块。

## 输入
A/B 模块文档、业务索引、stale 报告、需求条目和边界对齐结果。

## 执行步骤
按职责、能力、数据、API、规则、状态、金额、库存、事务、并发、幂等、缓存、消息、外部服务、权限、正确性、维护性、扩展性、缺陷和迁移难度逐项对照。

## 输出
比较报告、优势/弱点、冲突、候选决策和问题，每项引用 A-*、B-*、REQ-*。

## 质量检查
双方至少 PARTIAL、文档存在、证据未过期、边界可对齐；推断不能作为比较事实。

## 失败处理
前置条件不满足时只输出阻塞清单，不生成合并方案或 Java 设计。
